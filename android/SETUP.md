# Руководство по установке и запуску Android приложения\n\n## Системные требования\n\n- **Android Studio**: 2023.1 или новее\n- **Java Development Kit (JDK)**: 17 или новее\n- **Android SDK**: 34 (можно установить через Android Studio)\n- **Gradle**: 8.0+ (включен в проект)\n- **Минимум RAM**: 8 GB\n- **Место на диске**: ~5 GB\n\n## Шаг 1: Подготовка рабочего окружения\n\n### Windows\n\n1. Скачайте и установите Android Studio: https://developer.android.com/studio\n2. При установке выберите стандартные компоненты\n3. После установки откройте Android Studio\n4. Перейдите в `Tools > SDK Manager`\n5. Установите:\n   - Android SDK Platform 34\n   - Build Tools 34.0.0\n   - Android Emulator\n   - Intel HAXM (для ускорения эмулятора)\n\n### macOS\n\n```bash\n# Установите через Homebrew\nbrew install android-studio\n\n# Или скачайте отсюда: https://developer.android.com/studio\n```\n\n### Linux\n\n```bash\n# Ubuntu/Debian\nsudo apt-get install android-studio\n\n# Или скачайте вручную с https://developer.android.com/studio\n```\n\n## Шаг 2: Клонирование проекта\n\n```bash\n# Клонируйте репозиторий\ngit clone https://github.com/igorsokolov152-spec/MustInverterMonitor.git\ncd MustInverterMonitor\n\n# Переключитесь на ветку с Android проектом\ngit checkout add-android\n```\n\n## Шаг 3: Открытие проекта в Android Studio\n\n1. Откройте Android Studio\n2. Выберите `File > Open`\n3. Навигируйте в папку `MustInverterMonitor/android`\n4. Нажмите `OK`\n5. Подождите синхронизации Gradle (может занять несколько минут)\n\n## Шаг 4: Создание виртуального устройства (Emulator)\n\nЕсли у вас нет физического Android устройства:\n\n1. В Android Studio нажмите `Tools > Device Manager`\n2. Нажмите `Create Device`\n3. Выберите модель (например, Pixel 6)\n4. Выберите Android 14 (API 34)\n5. Нажмите `Next` и `Finish`\n6. В списке устройств нажмите кнопку Play для запуска эмулятора\n\n## Шаг 5: Запуск приложения\n\n### Через Android Studio\n\n1. Убедитесь, что эмулятор запущен или устройство подключено\n2. Нажмите зелёную кнопку `Run 'app'` (или Shift+F10)\n3. Выберите целевое устройство\n4. Приложение будет установлено и запущено\n\n### Через командную строку\n\n```bash\ncd android\n\n# Сборка и установка на устройство/эмулятор\n./gradlew installDebug\n\n# Или просто собрать APK\n./gradlew build\n```\n\n## Шаг 6: Создание APK для раздачи\n\n### Debug APK (для тестирования)\n\n```bash\ncd android\n./gradlew assembleDebug\n```\n\nПолученный файл: `android/app/build/outputs/apk/debug/app-debug.apk`\n\n### Release APK (для продакшена)\n\nДля создания release APK нужна подпись ключом:\n\n```bash\n# 1. Создайте keystore (один раз)\nkeytool -genkey -v -keystore my-release-key.keystore -keyalg RSA -keysize 2048 -validity 10000 -alias my-key-alias\n\n# 2. Поместите файл в папку android/ или ~/.android/\n\n# 3. Создайте или обновите файл keystore.properties в папке android/\n```\n\n**android/keystore.properties:**\n```properties\nstoreFile=my-release-key.keystore\nstorePassword=YOUR_PASSWORD\nkeyAlias=my-key-alias\nkeyPassword=YOUR_PASSWORD\n```\n\n**Затем соберите:**\n```bash\n./gradlew assembleRelease\n```\n\nPолученный файл: `android/app/build/outputs/apk/release/app-release.apk`\n\n## Возможные проблемы\n\n### Gradle Sync ошибки\n\n```bash\n# Очистите кэш\n./gradlew clean\n./gradlew build\n```\n\n### Эмулятор не запускается\n\n1. Убедитесь, что включена виртуализация в BIOS\n2. Отключите другие гиперvisors\n3. Переустановите HAXM/KVM\n\n### Приложение крашится при запуске\n\n1. Проверьте Logcat в Android Studio (`View > Tool Windows > Logcat`)\n2. Убедитесь, что Android SDK 34 установлен\n3. Очистите и пересоберите проект\n\n## Первый запуск\n\n1. Приложение откроется на экране списка устройств\n2. Нажмите кнопку \"+\" для добавления устройства\n3. Введите название и IP адрес инвертора\n4. Нажмите \"Add\"\n5. Откройте устройство чтобы видеть метрики\n\n## Тестирование\n\n```bash\n# Unit тесты\n./gradlew test\n\n# UI тесты (на устройстве/эмуляторе)\n./gradlew connectedAndroidTest\n```\n\n## Полезные ссылки\n\n- [Android Developer Guide](https://developer.android.com/guide)\n- [Jetpack Compose Documentation](https://developer.android.com/jetpack/compose/documentation)\n- [Android Studio Help](https://developer.android.com/studio/intro)\n- [Gradle Documentation](https://gradle.org/)\n\n## Контакты и поддержка\n\nЕсли у вас возникли проблемы:\n1. Проверьте логи в Logcat\n2. Посмотрите консоль Gradle\n3. Откройте issue в репозитории\n"
