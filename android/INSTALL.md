# Как установить APK на Android устройство\n\n## Быстрый старт\n\n### 1. Скачайте готовый APK\n\nСкачайте файл `app-debug.apk` из репозитория:\n- Перейдите на ветку `add-android`\n- Навигируйте: `android/app/build/outputs/apk/debug/app-debug.apk`\n- Нажмите кнопку Download\n\n**Или соберите сами:**\n```bash\ncd android\n./gradlew assembleDebug\n```\n\nAPK будет находиться: `android/app/build/outputs/apk/debug/app-debug.apk`\n\n---\n\n## Способ 1: Через USB (Рекомендуется)\n\n### На компьютере:\n\n1. **Установите Android Debug Bridge (ADB)**\n   \n   **Windows:**\n   ```bash\n   # Через Chocolatey\n   choco install adb\n   \n   # Или скачайте Android Studio Platform-Tools:\n   # https://developer.android.com/tools/releases/platform-tools\n   ```\n   \n   **macOS:**\n   ```bash\n   brew install android-platform-tools\n   ```\n   \n   **Linux:**\n   ```bash\n   sudo apt-get install android-tools-adb\n   ```\n\n2. **Подключите устройство USB кабелем**\n\n3. **Включите режим разработчика на телефоне:**\n   - Откройте Параметры\n   - Перейдите в \"О телефоне\" (или \"О устройстве\")\n   - Найдите \"Номер сборки\"\n   - Нажимайте на него 7 раз, пока не появится сообщение \"Вы разработчик\"\n\n4. **Разрешите отладку по USB:**\n   - Вернитесь в Параметры\n   - Перейдите в \"Параметры разработчика\"\n   - Включите \"Отладка по USB\"\n   - Подтвердите на телефоне когда появится запрос\n\n5. **Установите APK:**\n   ```bash\n   adb install app-debug.apk\n   ```\n   \n   или\n   \n   ```bash\n   cd android\n   ./gradlew installDebug\n   ```\n\n6. **Проверьте установку:**\n   ```bash\n   adb devices\n   ```\n\n---\n\n## Способ 2: Через Email/Облако\n\n1. **Скачайте APK на компьютер**\n\n2. **Отправьте себе по email или загрузите в облако** (Google Drive, Dropbox и т.д.)\n\n3. **На телефоне:**\n   - Откройте email/облако\n   - Скачайте APK файл\n   - Нажмите на скачанный файл\n   - Если появится предупреждение, разрешите установку из неизвестных источников:\n     - Параметры > Безопасность > Неизвестные источники > ВКЛ\n   - Нажмите \"Установить\"\n   - Дождитесь завершения\n\n---\n\n## Способ 3: Через QR код\n\n1. **Сгенерируйте QR код** для ссылки на APK (используйте любой QR генератор)\n\n2. **Отсканируйте QR кодом** на телефоне\n\n3. **Скачайте и установите** как в Способе 2\n\n---\n\n## Способ 4: Через Android File Transfer (macOS)\n\n1. **Скачайте Android File Transfer:** https://www.android.com/filetransfer/\n\n2. **Подключите телефон через USB**\n\n3. **Откройте Android File Transfer**\n\n4. **Перетащите APK файл в папку Downloads**\n\n5. **На телефоне откройте файловый менеджер и установите APK**\n\n---\n\n## Как запустить приложение\n\n### Через компьютер (если подключено по USB):\n```bash\nadb shell am start -n com.mustinverter.monitor/.MainActivity\n```\n\n### На телефоне:\n1. Откройте приложения\n2. Найдите \"MUST Inverter Monitor\"\n3. Нажмите на него\n\n---\n\n## Первый запуск\n\n### Требуемые разрешения:\n- ✅ Интернет (обязательно)\n- ✅ Доступ к сети (для UDP/HTTP)\n\n### Действия:\n1. Приложение откроется на экране \"Устройства\"\n2. Нажмите кнопку \"+\" в правом нижнем углу\n3. Введите:\n   - **Имя устройства** (например: \"Inverter 1\")\n   - **IP адрес** (например: 192.168.1.100)\n4. Нажмите \"Add\"\n5. Откройте устройство из списка\n6. Вы увидите метрики инвертора\n\n---\n\n## Удаление приложения\n\n### Через компьютер:\n```bash\nadb uninstall com.mustinverter.monitor\n```\n\n### На телефоне:\n1. Параметры > Приложения\n2. Найдите \"MUST Inverter Monitor\"\n3. Нажмите > Удалить\n\n---\n\n## Решение проблем\n\n### \"Cannot read file\" ошибка\n- Убедитесь, что APK файл не повреждён\n- Пересоберите: `./gradlew assembleDebug`\n\n### \"Installation failed\" при установке через ADB\n```bash\n# Очистите предыдущую версию\nadb uninstall com.mustinverter.monitor\n\n# Затем установите снова\nadb install app-debug.apk\n```\n\n### Приложение не подключается к инвертору\n- Проверьте IP адрес инвертора\n- Убедитесь, что телефон и инвертор в одной сети\n- Проверьте, что инвертор включен\n\n### Медленное копирование через ADB\n```bash\n# Используйте tcpip для беспроводной установки\nadb tcpip 5555\nadb connect <IP_ТЕЛЕФОНА>:5555\nadb install app-debug.apk\n```\n\n---\n\n## Ссылки\n\n- [Android Debug Bridge (ADB) Документация](https://developer.android.com/studio/command-line/adb)\n- [Режим разработчика на Android](https://developer.android.com/studio/debug/dev-options)\n- [Установка приложений на Android](https://support.google.com/android/answer/9950570)\n\n---\n\n## Получение логов для отладки\n\n```bash\n# Просмотр всех логов\nadb logcat\n\n# Только логи приложения\nadb logcat | grep com.mustinverter.monitor\n\n# Сохранить логи в файл\nadb logcat > logcat.txt\n\n# Очистить логи\nadb logcat -c\n```\n"
