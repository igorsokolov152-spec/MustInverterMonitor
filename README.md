# MustInverterMonitor (MVP)

iOS app (SwiftUI) для мониторинга PV18-6248 ECO (MUST).

Запуск:
- Открыть Xcode 14+, выбрать iOS 15+ как deployment target.
- Собрать и запустить на симуляторе/устройстве.
- В приложении можно добавить IP вручную или использовать встроенный симулятор для тестирования.

Что реализовано:
- Список устройств, добавление/удаление.
- Дашборд устройства с метриками (voltage/current/power/temp).
- Экран настроек (эмуляция применения).
- Локальное сохранение состояния в documents/inverters.json.

Дальнейшие задачи:
- Реальная интеграция UDP/HTTP по спецификации PV18-6248 ECO.
- Core Data вместо JSON (если нужны сложные истории/фильтрация).
- Фоновые обновления, экспорт CSV, аутентификация.
