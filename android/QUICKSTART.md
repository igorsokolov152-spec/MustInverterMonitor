# 🚀 Быстрый старт - MUST Inverter Monitor Android\n\n## Для нетерпеливых 😄\n\n### Windows (Самый простой способ)\n\n1. **Скачайте репозиторий:**\n   ```bash\n   git clone https://github.com/igorsokolov152-spec/MustInverterMonitor.git\n   cd MustInverterMonitor/android\n   ```\n\n2. **Двойной клик на `build-and-install.bat`**\n   - Автоматически соберет APK\n   - Автоматически установит на устройство\n\n3. **Готово!** Приложение запустится на вашем телефоне\n\n---\n\n### macOS/Linux\n\n```bash\ncd android\nbash build.sh debug\n./gradlew installDebug\n```\n\n---\n\n## 📱 Требования\n\n✅ **На компьютере:**\n- Android Studio (или только SDK tools)\n- Java 17+\n- 5 GB свободного места\n\n✅ **На телефоне:**\n- Android 7.0+ (API 24+)\n- USB кабель (или WiFi подключение)\n- USB Debug включен\n\n---\n\n## 🔧 Включение USB Debug на телефоне\n\n1. Параметры → О телефоне\n2. Нажимайте \"Номер сборки\" 7 раз\n3. Параметры → Параметры разработчика → USB Debug ✅\n\n---\n\n## 📦 Готовые файлы после сборки\n\nПосле запуска `build-and-install.bat` APK будет здесь:\n```\nandroid/app/build/outputs/apk/debug/app-debug.apk\n```\n\n**Размер:** ~4-5 MB\n\n---\n\n## 🎯 Первый запуск приложения\n\n1. Приложение откроется на главном экране\n2. Нажмите **\"+\"** в углу\n3. Добавьте устройство:\n   - Название: любое (например \"Мой инвертор\")\n   - IP адрес: 192.168.1.100 (IP вашего инвертора)\n4. Нажмите **\"Add\"**\n5. Откройте устройство из списка\n6. Видите метрики! ✅\n\n---\n\n## ⚡ Команды вручную\n\n```bash\ncd android\n\n# Только сборка\nmake debug              # или: ./gradlew assembleDebug\n\n# Сборка + установка\nmake install            # или: ./gradlew installDebug\n\n# Запуск на устройстве\nmake run\n\n# Просмотр логов\nmake logs               # или: adb logcat\n\n# Тесты\nmake test\n```\n\n---\n\n## 🐛 Если что-то не работает\n\n### \"Устройство не найдено\"\n```bash\nadb devices                 # Должно показать ваше устройство\nadb kill-server\nadb start-server\n```\n\n### \"Build failed\"\n```bash\ncd android\n./gradlew clean\n./gradlew build\n```\n\n### \"Installation failed\"\n```bash\nadb uninstall com.mustinverter.monitor\n./gradlew installDebug\n```\n\n---\n\n## 📚 Подробная документация\n\n- **[SETUP.md](./SETUP.md)** - Полная подготовка окружения\n- **[INSTALL.md](./INSTALL.md)** - Все способы установки APK\n- **[README.md](./README.md)** - Архитектура приложения\n\n---\n\n## 🔗 Полезные ссылки\n\n- [Android Developer Docs](https://developer.android.com/docs)\n- [Jetpack Compose](https://developer.android.com/jetpack/compose)\n- [Android Studio Download](https://developer.android.com/studio)\n- [Platform Tools Download](https://developer.android.com/tools/releases/platform-tools)\n\n---\n\n## ✨ Что дальше?\n\nПосле успешного тестирования на Android:\n- [ ] Интеграция с реальным API инвертора\n- [ ] Локальное сохранение данных\n- [ ] Real-time обновления\n- [ ] Экспорт в CSV\n- [ ] Push уведомления\n\n---\n\n**Вопросы?** Создайте issue в репозитории!\n"
